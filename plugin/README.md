# Codex Antigravity
 
This plugin starts the local `codex-antigravity-mcp` server. It requires an authenticated local `agy` executable. Set `ANTIGRAVITY_AGY_PATH` when `agy` is not on `PATH`.

Sessions default to Antigravity's non-sandboxed `plan` mode with `skipPermissions: true` for autonomous, non-blocking execution inside the declared workspace. Use `accept-edits` when modifications, refactors, or fixes are intended.
